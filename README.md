1. Title
Storage Estimator - Main Version
2. Purpose
This Python program estimates how much storage space is needed for a set of files. It was created for CS-117 Lab 10 and is now version-controlled with Git.
3. How to Run
4. Make sure Python is installed.
5. Open a terminal in this folder.
6. Run:

   python storage\_estimator.py

7. Example
Input: 5 files of 200 MB each
Output: Total storage needed: 1000 MB
